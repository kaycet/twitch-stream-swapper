How to use

1 Add channels: type a username, then click Add channel. Drag items to reorder priority.
2 Enable Auto-Swap: toggle it on. If no Twitch tab exists, one opens and only that tab is managed.
3 Jump back: use the return arrow to focus the managed Twitch tab.
4 Category fallback: toggle it on, type a category, then apply.
5 More settings: open Options for interval, themes, supporter features, and advanced config.
Tip Closing the managed Twitch tab turns Auto-Swap off automatically.
